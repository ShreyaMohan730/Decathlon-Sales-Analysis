# Decathlon Sales Analysis | Interactive BI Dashboard

## Project Overview
This project focuses on analysing Decathlon sales data to evaluate business performance, customer behaviour, sales trends, and customer retention.

An end-to-end ETL process was performed using Power Query to filter and prepare the data, followed by KPI development and year-over-year (YoY) analysis. The results were presented through an interactive dashboard to support data-driven business insights.

## Project Objectives
- Analyse overall sales performance and growth.
- Monitor order and customer trends.
- Evaluate average order value and customer retention.
- Understand sales distribution by gender.
- Compare key business metrics across years.
- Present insights through an interactive dashboard.

## Tools & Technologies
- **Microsoft Excel:** Data analysis and reporting.
- **Power Query:** ETL process and data preparation.
- **Dashboard Visualisation:** Interactive business performance dashboard.

## ETL Process
Performed ETL (Extract, Transform, Load) to prepare the sales data for analysis.

- Imported the source sales data.
- Used Power Query to filter and transform the data.
- Prepared the data for KPI calculations and dashboard reporting.

## Key Performance Indicators (KPIs)

The dashboard tracks the following business metrics:

| KPI | Analysis |
|---|---|
| Total Sales | Overall sales performance |
| Sales YoY | Year-over-year sales growth |
| Total Orders | Total number of orders |
| Orders YoY % | Year-over-year order growth |
| Total Customers | Total unique customers |
| Customers YoY % | Year-over-year customer growth |
| Average Order Value (AOV) | Average value per order |
| AOV YoY % | Year-over-year change in AOV |
| Retained Customers | Customers who purchased again |
| Retained Customers YoY % | Year-over-year change in retained customers |
| Gender-wise Sales | Sales distribution by gender |

## Dashboard Features
- Interactive dashboard for exploring sales performance.
- KPI cards for monitoring key business metrics.
- Year-over-year performance comparisons.
- Customer retention analysis.
- Gender-wise sales analysis.
- Visual representation of important business metrics.

## Business Value
The analysis provides a consolidated view of sales performance and customer behaviour. It helps identify changes in sales, order volume, customer growth, average order value, and customer retention, supporting informed business decisions.

## Conclusion
This project demonstrates practical skills in ETL, data preparation, KPI development, year-over-year analysis, customer analytics, and interactive dashboard creation.

It showcases the application of business intelligence techniques to transform raw sales data into meaningful business insights.
